# Vatsal Chaudhary — Portfolio

Personal portfolio website for Vatsal Chaudhary, a Computer Science & Engineering student at Symbiosis Institute of Technology, Pune.

**Live:** [vatsalchaudhary.netlify.app](https://vatsalchaudhary.netlify.app/)

The site is a place to showcase things I've built, experiments I've worked on, and the technologies I'm currently learning.

---

## About

I like building things mostly because I want to understand how they work.

A project might start as a simple idea, a problem I want to solve, or just something I was curious about. I learn best by actually making things, breaking them, fixing them, and seeing what happens.

This portfolio follows the same approach — it's an ongoing project rather than a finished product.

---

## What's Inside

- **Home** — A quick introduction and overview

---

## Design

The visual direction is built around a simple palette:
- Near black
- Warm off-white
- Red accents

The goal was to keep the site technical without making it feel like a terminal simulator or a generic developer template.

A lot of the design is intentionally quiet — large typography, thin borders, monospace details, and occasional motion.

## Getting Started

Clone the repository:
```bash
git clone https://github.com/vatsalost/portfolio.git
cd portfolio
```

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

The development server will start locally and Vite will provide the local URL.

---

## Available Scripts

- `npm run dev` — Runs the development server.
- `npm run build` — Creates a production build.
- `npm run preview` — Previews the production build locally.
- `npm run lint` — Runs the project's linting checks.

## Why I Built It This Way

I didn't want the portfolio to feel like a collection of screenshots inside a template.

Instead, I wanted it to feel like a small project of its own.

That means experimenting with:
- typography
- page transitions
- scrolling
- subtle interactions
- project presentation
- responsive layouts
- different ways of showing technical work

Some parts are more experimental than others. That's intentional.
