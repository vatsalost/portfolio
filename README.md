## ⚡ Overview

A high-end, bespoke personal portfolio website inspired by avant-garde Japanese experimental design studios (*otsuka-air.jp*), built to showcase collegiate hackathon winners, systems developer tools, and GPU algorithm visualizers.

- **Color Palette**: Obsidian Black (`#0A0A0A`), Bone White (`#F5F5F0`), and Laser Crimson (`#E10600`) as a precise accent.
- **Motion & Interaction**: Smooth scrolling powered by Lenis, scroll-linked animations via GSAP ScrollTrigger, and cybernetic cursor tracking.
- **Component Systems**: Custom implementations of [ReactBits](https://reactbits.dev/) physics (radial cursor spotlights, 3D perspective tilt, stable decrypted text ciphers) and [Untitled UI](https://www.untitledui.com/react/components) telemetry patterns.
- **react.dev Code Cards**: Interactive, syntax-highlighted code editor cards in the Competency Matrix with macOS/Linux window controls, line numbers, and one-click copy feedback.

- **Core**: React 18, Vite

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Installation
```bash
# Clone the repository
git clone https://github.com/vatsalost/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The site will be live at `http://localhost:5173/`.

### Production Build
```bash
npm run build
npm run preview
```
